# Игровые ассеты

## Уже подключено

В сетевой сцене и выборе героя используются 11 исходных PNG из [Kenney Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon): шесть персонажей, стрела, удар, искра, огонь и лечебный эффект. Автор Kenney распространяет этот набор по [CC0](https://creativecommons.org/publicdomain/zero/1.0/); копия лицензии находится рядом с файлами в `client/public/assets/kenney/tiny-dungeon/License.txt`. Из архива взяты только используемые 16×16 PNG, чтобы не увеличивать загрузку клиента без пользы.

| Герой из БД | Файл | Визуальная роль |
| --- | --- | --- |
| `warrior` | `warrior.png` | воин в броне |
| `assassin` | `assassin.png` | персонаж в фиолетовом капюшоне |
| `mage` | `mage.png` | маг |
| `support` | `support.png` | жрец |
| `marksman` | `marksman.png` | следопыт |
| `fighter` | `fighter.png` | красный берсерк |

Анимация шага, атаки и эффектов пока создаётся в Phaser движением, масштабом и прозрачностью статичных спрайтов. Выстрелы и эффекты привязаны к подтверждённым событиям сервера; летящий снаряд — только визуализация уже рассчитанного попадания.

## Что нужно для законченного визуального стиля

1. **Герои:** шесть согласованных наборов сверху или под углом сверху. Для каждого нужны кадры `idle`, `run`, `attack`, `cast`, `hit`, `death` и направление взгляда хотя бы влево/вправо. Экспорт: прозрачные PNG или атлас PNG + JSON с размерами кадра и точкой опоры; одинаковый масштаб для всех героев. Отдельно нужны портреты для выбора героя, минимум 256×256.
2. **Способности:** для каждого Q/1/2/3 — читаемый значок 64×64 и последовательность эффекта с указанной длительностью. Особенно нужны телепорт/Dash, щит, лечение, ледяная волна, метеор, удар по области и воскрешение. Визуальное время можно менять независимо от серверного cooldown и урона.
3. **Базовые атаки:** отдельные стрелы, магические снаряды и ближние удары с фазами полёта/попадания. Их направление, длина и скорость должны быть настраиваемыми в клиенте; попадание по-прежнему определяет сервер.
4. **Арена и UI:** единая карта с читаемыми границами, безопасными зонами и контрастными командными цветами; иконки здоровья, маны, cooldown; мобильные кнопки в том же стиле. Проверять читаемость на ширине 320–390 px.
5. **Звук:** короткие SFX атаки, получения урона, каста, попадания, смерти и конца матча; отдельная громкость эффектов и возможность отключения.

Для всех новых внешних файлов сохраняйте URL источника, автора, версию и лицензию в этом документе. До выбора окончательного художественного направления CC0 спрайты остаются временным визуальным набором.
